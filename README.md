# Metal language support

Adds syntax highlighting and snippets for Metal (`.mtl`) files.

## Editors

### VS Code

Copy or symlink this folder into your extensions directory, then reload VS Code:

```bash
cp -r . ~/.vscode/extensions/language-metal
```

Or install via VSIX: package with `vsce package`, then `Extensions: Install from VSIX...`.

### Atom

Install via Atom's package manager (Preferences → Install → Packages) or from a shell:

```bash
apm install language-metal
```
